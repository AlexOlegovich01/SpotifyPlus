# SpotifyPlus

🇬🇧 [English version](README.md)

Пользовательский скрипт для [Tampermonkey](https://www.tampermonkey.net/), который добавляет удобные функции в веб-плеер Spotify (`open.spotify.com`): выделение текста, управление громкостью и перемоткой с клавиатуры и колесом мыши и другое.

## Возможности

| Действие | Результат |
| --- | --- |
| Зажать **Shift** и вести мышью | Выделять и копировать любой текст на странице |
| **↑ / ↓** | Громкость ±2% |
| **← / →** | Перемотка ±2 секунды |
| Колесо мыши над **ползунком громкости** | Громкость ±5% |
| Колесо мыши над **шкалой времени** | Перемотка ±20 секунд |
| **Пробел** | Пауза / воспроизведение |
| **Ctrl + → / Ctrl + ←** | Следующий / предыдущий трек |
| **Ctrl + C** (когда ничего не выделено) | Скопировать текущий трек в виде `Артист — Название` |

Горячие клавиши не срабатывают, пока вы вводите текст в поле (например, в строке поиска). Если текст выделен, **Ctrl + C** работает как обычное копирование.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для вашего браузера.
2. Откройте [`SpotifyPlus.user.js`](SpotifyPlus.user.js) (кнопка **Raw** на GitHub) — Tampermonkey предложит установить скрипт. Либо создайте новый скрипт в панели Tampermonkey и вставьте содержимое файла.
3. Откройте или перезагрузите [open.spotify.com](https://open.spotify.com/).

## Примечания

- Скрипт находит элементы управления Spotify по атрибутам `data-testid` (например, `volume-bar`, `playback-progressbar`, `control-button-playpause`). Spotify может изменить их при обновлении; если функция перестала работать, проверьте селекторы в DevTools браузера и поправьте их в коде скрипта.
- Скрипт работает только на `https://open.spotify.com/*` и не требует особых разрешений (`@grant none`).
